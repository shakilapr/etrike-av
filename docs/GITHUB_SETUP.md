# GitHub setup — etrike project

## Overview

The etrike project spans multiple Git repos. One small config repo ties them all together.

```
github.com/etrike/
├── etrike-config/              ← config repo (docker, vehicle, docs, manifest)
├── etrike_controller/          ← our custom controller package
├── etrike_vehicle_interface/   ← our vehicle interface package
├── etrike_bridge/              ← our CAN/serial bridge
├── etrike_msgs/                ← our custom ROS messages
├── autoware_universe/          ← fork (if we modify official packages)
└── autoware_core/              ← fork (if we modify official packages)
```

This is the small repo that holds everything NOT pulled by `vcs import`.

cd ~/av_project

```bash
git remote add origin git@github.com:etrike/etrike-config.git
git branch -M main

```

## Step 2 — Create our package repos

For each custom package, create a repo on GitHub and push:

```bash
# On GitHub: create etrike/etrike_controller (empty, no README)

cd ~/av_project/autoware/src/our_packages/our_controller

# Initialize the package (example)
ros2 pkg create etrike_controller --dependencies rclcpp std_msgs

git init
git add .
git commit -m "Initial etrike_controller"
git remote add origin git@github.com:etrike/etrike_controller.git
git branch -M main
git push -u origin main
```

Repeat for each custom package.

## Step 3 — Fork Autoware repos (only what we modify)

### On GitHub (browser)

Fork only the repos we'll change. Most likely candidates:

```
autowarefoundation/autoware_universe  →  etrike/autoware_universe
autowarefoundation/autoware_core      →  etrike/autoware_core
```

### On Linux — add upstream to track original

```bash
cd ~/av_project/autoware/src/universe/autoware_universe
git remote set-url origin git@github.com:etrike/autoware_universe.git
git remote add upstream https://github.com/autowarefoundation/autoware_universe.git
git checkout -b etrike-dev
git push -u origin etrike-dev
```

## Step 4 — Write `our_autoware.repos`

This is the single file that describes the entire source tree.

```bash
cp repositories/autoware.repos repositories/our_autoware.repos
```

Then edit it. Untouched repos keep upstream URLs and pinned versions. Modified repos point to our forks. Custom packages added at the bottom:

```yaml
repositories:
  # === UNTOUCHED UPSTREAM ===
  core/autoware_msgs:
    type: git
    url: https://github.com/autowarefoundation/autoware_msgs.git
    version: 1.13.0

  core/autoware_cmake:
    type: git
    url: https://github.com/autowarefoundation/autoware_cmake.git
    version: 1.4.0

  # ... all other untouched repos ...

  # === OUR FORKS (modified official packages) ===
  universe/autoware_universe:
    type: git
    url: git@github.com:etrike/autoware_universe.git
    version: etrike-dev

  # === OUR CUSTOM PACKAGES ===
  our_packages/etrike_controller:
    type: git
    url: git@github.com:etrike/etrike_controller.git
    version: main

  our_packages/etrike_vehicle_interface:
    type: git
    url: git@github.com:etrike/etrike_vehicle_interface.git
    version: main

  our_packages/etrike_bridge:
    type: git
    url: git@github.com:etrike/etrike_bridge.git
    version: main

  our_packages/etrike_msgs:
    type: git
    url: git@github.com:etrike/etrike_msgs.git
    version: main
```

Commit and push:

```bash
cd ~/av_project
git add repositories/our_autoware.repos
git commit -m "Add our_autoware.repos manifest"
git push
```

## Step 5 — Recovery from scratch

If the Linux machine dies:

```bash
# 1. Clone config
git clone git@github.com:etrike/etrike-config.git ~/av_project

# 2. Pull all source (33 repos, correct forks, correct branches)
cd ~/av_project/autoware
mkdir -p src
vcs import src < ../repositories/our_autoware.repos

# 3. Pull data from backup
# AWSIM, maps, bags, models → restore from NAS/S3/etc.

# 4. Build
~/av_project/docker/build.sh

# 5. Launch
~/av_project/docker/run.sh
```

```

├── autoware/
│   └── src/
│       ├── core/                      ← vcs import (untouched upstream)
│       ├── universe/                  ← vcs import (our fork if modified)
│       ├── launcher/                  ← vcs import (untouched)
│       ├── sensor_component/          ← vcs import (untouched)
│       ├── simulator/                 ← vcs import (untouched)
│       ├── tools/                     ← vcs import (untouched)
│       └── our_packages/              ← vcs import (our repos)
├── vehicle/                           ← tracked in config repo
├── docker/                            ← tracked in config repo
├── docs/                              ← tracked in config repo
├── repositories/                      ← tracked in config repo
├── simulator/AWSIM/                   ← gitignored (separate backup)
└── data/                              ← gitignored (separate backup)
```
